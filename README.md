# Parry Arena

Game top-down 2D (HTML + CSS + JavaScript thuần, không dùng thư viện, không cần build).

## Chạy
- Mở `index.html` bằng trình duyệt, hoặc
- Upload lên GitHub rồi bật GitHub Pages (Settings -> Pages -> Branch `main`, thư mục `/ (root)`).

## Điều khiển
- WASD: di chuyển, chuột: ngắm
- Click trái: đánh · Click phải / Shift: đỡ đòn (parry)
- Space: lăn né · Q: kỹ năng (mở ở Lv2)
- 1/2/3: dung hợp vũ khí (sau khi hạ boss) · R: chọn lại class
